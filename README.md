## 🇺🇸 English Version

### **The Vision**
**BeeNouns** is a bridge between traditional artisanal beekeeping and the decentralized future. We exchange digital empowerment for real-world knowledge. By providing beekeepers with professional, AI-generated web profiles and Farcaster identities, we help them overcome market distrust and financial barriers while onboarding them into the **Nouns DAO** ecosystem.

### **Core Features**
- 🤖 **AI-Crafted Profiles:** Generates high-end marketing copy and strategic analysis using **Google Gemini 3 Pro**.
- ⌐◨-◨ **Nounish Identity:** Pure pixel-art aesthetic based on the Nouns glasses (Noggles).
- 🟣 **Farcaster Integration:** Automatic reservation of social handles to build a decentralized community of producers.
- 🛡️ **Identity Verification:** A "Social-Proof" system to ensure apiaries are real and combat honey fraud.
- 🌐 **Web3 Ready:** Profiles compatible with `.eth` domains and IPFS deployment.

### **Tech Stack**
| Category | Tools |
| :--- | :--- |
| **Frontend** | React 19, TypeScript, Tailwind CSS |
| **Intelligence** | Google Gemini API (GenAI SDK) |
| **Icons** | Lucide React |
| **Social** | Farcaster Protocol / Warpcast |

### **Pain Points Addressed**
1. **The Trust Gap:** Beekeepers often distrust "blockchain". We provide immediate value (a website) first.
2. **Market Saturation:** IA helps them find their "Premium" angle.
3. **Traceability:** Preparing the ground for on-chain honey tracking.

## 🇪🇸 Versión en Español

### **La Visión**
**BeeNouns** es un puente entre la apicultura artesanal tradicional y el futuro descentralizado. Intercambiamos empoderamiento digital por conocimiento real. Al proporcionar a los apicultores perfiles web profesionales generados por IA e identidades en Farcaster, les ayudamos a superar la desconfianza del mercado y las barreras financieras mientras los integramos al ecosistema de **Nouns DAO**.

### **Características Principales**
- 🤖 **Perfiles con IA:** Genera textos de marketing de alta gama y análisis estratégicos usando **Google Gemini 3 Pro**.
- ⌐◨-◨ **Identidad Nounish:** Estética pura de pixel-art basada en los lentes de Nouns (Noggles).
- 🟣 **Integración con Farcaster:** Reserva automática de handles sociales para construir una comunidad descentralizada de productores.
- 🛡️ **Verificación de Identidad:** Sistema de "Prueba Social" para asegurar que los apiarios sean reales y combatir el fraude de la miel.
- 🌐 **Web3 Ready:** Perfiles compatibles con dominios `.eth` y despliegue en IPFS.

### **Stack Tecnológico**

### **Dolores que Resolvemos**
1. **Brecha de Desconfianza:** El apicultor suele desconfiar de la "blockchain". Nosotros entregamos valor inmediato (una web) primero.
2. **Saturación de Mercado:** La IA les ayuda a encontrar su ángulo "Premium".
3. **Trazabilidad:** Preparando el terreno para el seguimiento de la miel on-chain.

## ⌐◨-◨ How to run / Cómo ejecutar

1. Clona el repositorio.
2. Instala las dependencias: `npm install`.
3. Asegúrate de tener tu `API_KEY` de Google Gemini configurada.
4. Ejecuta el entorno de desarrollo: `npm run dev`.
